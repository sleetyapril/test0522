GAME RULES · MARKET → DIFFICULTY

주가가 움직이면, 적들도 움직입니다

30초 슬라이딩 윈도우 변화율이 실시간으로 게임 난이도를 결정합니다

시장 조건 (30s 변화율) 게임 반응 사용자 경험 난이도 배수
▲ ≥ +0.3% 자동 탄막 강화 · 쿨다운 단축 · 3연발 상승장 — 공격 쉬움, 점수 보너스 ×0.8
◆ ±0.1% 기본 공격 · 기본 이동 관망장 — 표준 난이도 ×1.0
▼ ≤ −0.3% 적 발사 간격 단축 · 조준탄 추가 하락장 — 긴장감 증가 ×1.5
▼▼ ≤ −0.7% 패닉 패턴 · 화면 흔들림 · 경고 배너 급락장 — 실패 가능성 급상승 ×2.0+
▼▼▼ ≤ −1.5% 강제 Alert Mode 진입 · 게임 중단 관심종목 즉시 확인 유도 ALERT

  • 현물 — KOSPI200 현물 (Naver)
  • 종목 — 개별 주식 선택 (KIS/Naver)
