PROBLEM · ALERT FATIGUE

숫자 알림은 너무 쉽게
무시됩니다

주가 알림은 대부분 숫자와 텍스트로 도착합니다. 하지만 업무 중이거나 이동 중일 때, 반복되는 알림은 금방 피로해지고 정작 중요한 급락 신호도 놓치기 쉽습니다.

PROBLEM 01

숫자 알림 피로

반복되는 가격 알림은 시간이 갈수록 무시되기 쉽습니다. 푸시가 쌓일수록 진짜 위험 신호와 일상 노이즈의 구분이 흐려집니다.

PROBLEM 02

급락장의 즉시성 부족

시장은 빠르게 움직이지만, 일반 알림은 긴급감을 충분히 전달하지 못합니다. 1.0% 급락도 화면에서는 그냥 글자 한 줄로만 보입니다.

PROBLEM 03

정보와 행동의 단절

시세 확인 앱과 관심종목 점검 행동은 분리되어 있어, 알림을 봐도 실제 대응으로 이어지기 어렵습니다.

FAQ

자주 묻는 질문

아니요. KOSPI Space Defender는 투자 판단이나 매매 추천을 하지 않습니다. 시장 변화를 게임형 알림으로 보여주는 warning UX 서비스이며, 모든 투자 판단은 사용자 본인의 책임입니다.

MVP에서는 계좌 연결 없이 관심종목을 직접 입력하는 방식으로 시작합니다. 향후 사용자가 원할 경우 증권앱 딥링크나 포트폴리오 연동을 검토할 수 있습니다.

MVP는 demo feed 또는 설정 가능한 API endpoint로 시작합니다. 추후 KIS, KRX, 상용 API 등 안정적인 실시간 데이터 연동을 검토합니다.

이번 베타는 자체 디자인의 추상 픽셀 심볼만 사용합니다. 공개 서비스에서도 기업 로고는 사용 권리와 브랜드 가이드 확인 없이는 사용하지 않으며, 대체 픽셀 심볼 시스템을 우선합니다.

사용자별 알림 임계값, quiet mode, 하루 알림 횟수 제한을 적용해 알림 피로를 줄이는 방향으로 설계합니다. 베타 기간 동안 적정값을 함께 찾아갈 예정입니다.
